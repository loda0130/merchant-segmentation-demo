## 六店模型与交互结果

|自动新增|自动剔除|扫描后成员 ID|可加入|待剔除|保护冲突|实际新增进出历史|
|---|---|---|---:|---:|---:|---:|
|开|开|900001、900003、900005|1|1|2|2|
|开|关|900001、900002、900003、900005|1|2|2|1|
|关|开|900003、900005|2|1|2|1|
|关|关|900002、900003、900005|2|2|2|0|

四种组合二次扫描均新增 0 条进出历史。浏览器双开流程另核对系统操作者、失败扫描前后成员、人工配置、保护项批量处理、版本更新后的候选、修改历史、启停与软删除。模型回归命令为 `node --test tests/segmentation-model.test.cjs`。
