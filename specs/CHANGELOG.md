# 商家圈组变更记录
## 未发布 · 2026-11-27
- 店铺 ID 成为圈选条件，支持输入多个完整 ID。移除累计充值金额条件、初始店铺 ID 输入框和配置店铺入口。
- 圈组列表新增「手动更新」，对当前启用圈组立即执行一次模拟全量扫描。扫描间隔仅支持 1 小时，创建和编辑中自动新增、自动剔除固定开启。
- 创建和编辑统一按「条件类型 → 运算符 → 值」维护条件，行间单独选择「且」或「或」。已有「且非」规则通过行内否定运算符回显，预览与扫描沿用相同匹配逻辑。
- 圈组详情聚焦组内店铺，移除「可加入」「待剔除」页签及手动批量处理，新增组内店铺明细的导出演示按钮。

## 0.2.0 · 2026-11-27
- 上线前的静态交互版以 `docs/index.html` 为入口。原设计入口迁至 `docs/design-preview.html`，五张参考图与公共组件示例均保留。
- 新增圈组列表、条件编辑与保存预览、独立自动开关、模拟扫描、成员与候选视图、人工配置与批量处理、两类历史、启停及软删除。
- 按圈组与店铺独立保存人工保护，应用候选前重验规则版本、扫描、当前匹配与成员状态。失败扫描沿用上次成功快照，系统进出历史只登记实际变更。
- 修正首版大金额回显的分位精度和重复候选计数。局部缩减编辑器空白，增强窄屏表单可达性。
- 圈组列表居中显示店铺数表头和数字，并拉开与自动维护列的间距。
- 列表新增两级圈选条件筛选。五个维度共享一个二级单选，查询与现有筛选项组合生效。
- 首个标签组也支持选择「且」「或」「且非」，全量扫描间隔改为仅有「24 小时」的下拉。
- 通过 14 个 Node.js 模型测试及 Windows Chrome 的本地 HTTP 流程与四档视口测试。Pages 的 `main /docs` 设置沿用当前仓库配置，业务版等待提交和发布确认。 [验收记录](TASK.md)
