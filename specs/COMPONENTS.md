# 标准组件

交互示例见 [组件库](../docs/components.html)，完整页面布局见 [管理工作台](../docs/index.html)。`docs/styles.css` 载入 `docs/ui/tokens.css` 和 `docs/ui/components.css`，示例交互位于 `docs/app.js`。配色、间距与文字层级遵循 [DESIGN.md](DESIGN.md)。

页面以 `.masthead`、`.workspace`、`.breadcrumb` 和 `.page-heading` 组织。筛选区以 `.panel` 包住 `.filter-grid` 和 `.filter-actions`，可折叠区使用 `details.more-filters`，不改变现有筛选行为。表格放在 `.table-scroll` 下，表头和数据列保持对应。页脚使用 `.panel-footer` 和 `.pagination`。

| 组件 | 适用场景与要求 |
| --- | --- |
| 主按钮、次按钮、文字按钮 | 主按钮用于当前区域的首要操作，次按钮用于取消或次要操作，文字按钮用于低强调度动作。页面跳转使用链接，触发交互使用按钮。 |
| 危险按钮、禁用按钮 | 危险按钮用于删除或清除等操作。条件不满足时使用原生 `disabled`，并通过区域说明交代可用条件。 |
| 状态标签 | 同时显示文字和颜色。组件示例中的启用、待处理、停用仅用于展示样式。 |
| 常规及折叠筛选 | 使用可见标签和清除入口。常用条件始终可见，低频条件可放入原生 `details`。折叠后提示已生效的条件。 |
| 紧凑型表格、分页 | 表格保留表头和匹配数，窄屏在表格范围内横向滚动。筛选变化回到第一页，页码超出范围时回到最后可用页。 |
| 批量操作 | 表头全选的范围应明确。组件页默认全选本页，保留跨页选择，筛选变化清除选择。显示已选数量，确认前明确受影响条数。 |
| 新增及编辑弹窗 | 使用有标题的原生 `dialog`。新增填充默认值，编辑预填当前值。校验失败保留表单并提示原因。 |
| 删除及重置确认 | 说明影响和恢复范围，默认焦点置于取消。确认后即时更新列表，取消或 Esc 关闭时保留原数据。 |
| 侧边抽屉 | 用于补充说明或详情。提供标题、关闭按钮、Esc 关闭和焦点恢复。 |
| 成功、失败及警告提示 | 清楚说明操作结果或可采取的后续操作。常规状态用 `role="status"`，需要及时读出的表单错误用 `role="alert"`。 |
| 空数据及加载状态 | 区分无记录、无匹配和正在加载。异步处理中防止重复触发，并在结束时解除忙碌状态。 |

组合及批量输入、复杂表头、冻结列、列设置、标签浮层、多级选择、图表和通用交互拆分属于后续复杂组件迁移。
