# Demo 验收清单

按项目勾选并在 [TASK.md](TASK.md) 记录实际验证环境、结果和待验证项。

## 功能

- [ ] 导航、表单、筛选、分页、批量操作及弹窗按需求工作。
- [ ] 验证空数据、无匹配、加载、失败、取消与确认。
- [ ] 键盘可访问主要控件，弹窗关闭后焦点返回合理位置。

## 视觉

- [ ] 页面遵循公共组件的配色、文字层级、间距与交互状态。
- [ ] 桌面和窄屏布局可用，横向滚动限定在表格区域。
- [ ] 在 1920×1080、1440×900、1280×800 实际运行页面，核对顶栏、标题、控件与筛选网格的计算样式，记录截图。
- [ ] 核对 12px 表格文字、表头及表体内边距。使用合理分组控制复杂宽表的阅读范围。
- [ ] 使用冻结列的页面检查左右滚动时表头和数据的对齐、冻结列背景、边缘遮挡、可见宽度及窄屏释放。
- [ ] 打开弹窗并确认内容和操作按钮可达，弹窗不会超出视口。

## 跨设备

- [ ] 在 Windows 和 macOS 的目标浏览器通过本地静态 HTTP 验证入口与核心流程。
- [ ] 路径为区分大小写的相对路径，文本使用 LF，JavaScript 语法检查通过。

## 部署

- [ ] Public 项目按 GitHub Pages 的 `main` 分支和 `/docs` 目录配置。
- [ ] 验证站点子路径中的页面链接、样式、脚本与静态资源。
- [ ] 涉密项目保持 Private，仅本地运行或内部交付。

## 数据安全

- [ ] 公开页面只使用虚构或脱敏的数据和资源。
- [ ] 整个 Public 仓库无真实业务数据、内部接口地址、访问凭据，以及未经授权公开的文档与截图。
