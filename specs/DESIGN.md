# 公共设计规范

## 布局与筛选

- 白色顶栏以 1px 边框与工作区分隔。全宽正文在常规桌面采用 `16px 20px 20px` 内边距，1600px 起采用 `18px 24px`。顶部放面包屑、标题和页面级操作。需要模块导航时可加紧凑侧栏。
- 白色筛选与结果面板采用细边框。筛选区使用 4 等分列，间距为行 12px、列 18px，字段标签间距 5px。900px 及以下使用两列，600px 及以下使用一列。粗指针设备适当增大控件，高度至少 40px。
- 输入和选择控件内边距为 `6px 9px`。主次按钮为 `6px 12px`，行内文字操作采用无边框透明背景及悬停下划线。保留键盘焦点样式。

## 表格、标签与反馈

- 表格采用 12px 字号、等宽数字和横向滚动容器。表头浅底、字重 600，内边距 `11px 10px`。表体采用白底和 1px 分割线，内边距 `12px 10px`。通用记录行高由内容决定。
- 数值右对齐，标签包含文字和语义色。无记录和无匹配均保留表头。分页显示页码且禁用已到边界的操作。
- 编辑、确认继续使用原生 `dialog` 和标题关联。基础弹窗宽度上限 650px、最大高度 85vh，确认上限 560px。弹窗保持焦点可追踪，危险确认默认焦点为取消，Esc 可退出。
- 使用平实的成功、警告和错误提示。示例只使用虚构数据，资源使用相对路径。

## 商家圈组专属设计（0.1.0）
本节为子项目规则，不回写母模板。精确字段参考见 [参考图索引](references/README.md) 和 [设计预览](../docs/design-preview.html)。图片中的样本值只表示示例，PRD 规则优先。

### 信息架构与视觉预算
- 顶栏 52px；全宽浅灰背景，白色面板，蓝色交互。正文13px、表格12px、辅助11–12px，主标题20px。禁止大面积装饰图、营销卡片和无意义留白。
- 默认列表优先显示圈组身份、条件、成员数、自动维护、提醒、状态、维护信息和操作。组名/ID合并，创建人与创建时间合并，更新人与更新时间合并。
- 桌面横向预算约1380px。1280视口表格局部滚动；若冻结，仅冻结身份列和操作列，并保证中间至少400px；小于900px取消冻结。不强制给短表冻结。
- 条件摘要最多三行；完整表达式在详情或可聚焦浮层中选择复制。每个时间字符串保持一行。
- 操作列约240px，容许自动换行。手动更新放在首位，运行中显示「更新中…」并禁用。业务CSS为行操作提供至少36×30px点击区，间距≥6px。
- 查询区域四列，900px两列、600px一列。禁用与只读不能只用浅灰颜色表达，要有文字原因。
- 列表的圈选条件使用两栏下拉。左栏选择条件维度，右栏单选具体条件，折叠后显示「维度 / 条件」。菜单支持清除、Esc 和点击外部关闭。

### 组件复用与例外
沿 docs/styles.css 加载 ui/tokens.css、ui/components.css；沿用 .masthead、.workspace、.panel、.field、.filter-grid、.table-scroll、.badge、.dialog-actions、.pagination。
docs/app.js 与模板 DOM ID 耦合，只保留供 components.html 演示；业务入口加载独立 segmentation.js 与 segmentation-model.js，不把模板脚本直接挂到缺少其DOM的业务页。
新增 docs/segmentation.css 仅做业务范围覆盖：复杂条件组、详情提醒、保护标签、行操作命中区、宽编辑器。保留公共文件原貌。
圈选条件在同一列表中维护。桌面每条依次显示组间关系、条件类型、条件值及移除按钮。窄屏将条件值单独换行。切换类型后显示对应的标签 ID 输入、店铺 ID 输入或类型与大类多选；已有的是否自营条件以同样的行结构回显。表达式实时同步，首条取反显示为「非」。
全量扫描间隔下拉仅显示「1 小时」。自动新增和自动剔除使用已勾选且禁用的控件，配合灰色标签和固定开启说明。
候选按钮区显示勾选数量和动作范围；无选择禁用；空/全无效输入不可提交。保护项仍可由人工明确处理。
错误定位到字段；保存失败保留草稿；取消/Esc恢复触发焦点。确认默认聚焦取消。加载期间禁用重复操作；不能只在控制台输出反馈。
