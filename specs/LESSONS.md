# 可复用经验

记录前查阅 PRD、DESIGN、COMPONENTS、CHECKLIST 等正式规范及已有记录。已被正式规范覆盖的经验无需重复记录。业务子项目提出可复用经验后，由用户确认是否沉淀到母模板。

## 从成熟页面确定视觉基准

| 字段 | 内容 |
| --- | --- |
| 问题 | 源文件声明、最终排布和浏览器计算样式可能给出不同数值。 |
| 原因 | 迭代追加的规则、内联样式及浏览器布局算法共同影响最终结果。 |
| 解决方案 | 先确认本地、远端和发布版本的内容一致，再按源码顺序定位规则，用运行态尺寸确定哪些参数适合变成 Token。将业务内容撑出的尺寸单独记录。 |
| 适用范围 | 从现有页面提取公共视觉体系。 |
| 是否已沉淀至正式规范 | 是。[阶段一视觉参数](DESIGN.md)及[验收清单](CHECKLIST.md)。 |
